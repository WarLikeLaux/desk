# desk

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

[English](README.md) | Русский

desk помогает держать задачи, таймеры и заметки на одной тёмной странице. Всё сохраняется в localStorage. Сборка и аккаунт не нужны. Единственный внешний запрос приложения загружает шрифты Google Fonts.

Три колонки: слева таймеры, в центре задачи, справа заметки и привычки. На компьютере рабочее пространство занимает один экран, длинные списки прокручиваются внутри колонок. На телефоне колонки складываются вертикально, задачи идут первыми.

## Задачи

- **Enter** добавляет задачу в конец активной секции. **Ctrl/Cmd + Enter** и **Shift + Enter** добавляют её в начало.
- **Чекбокс** завершает задачу. Завершённые задачи перемещаются вниз. В общем списке показываются первые три, остальные можно раскрыть.
- **Двойной клик**, кнопка **⋯** или оценка времени открывают редактор названия, оценки и ссылок. Кнопка «Сохранить» применяет изменения, Esc отменяет.
- **Кнопка времени** открывает поле слева от иконки часов. Поддерживаются минуты, часы и диапазоны: `30 мин`, `1–2 ч`, `30 мин – 1 ч`. Enter возвращает фокус к названию задачи, оценка сохраняется при добавлении.
- В оценках задач и длительностях таймеров единицы отображаются полностью: `1 - 2 часа`, `30 - 45 минут`, `1 час 30 минут`. Сокращения при вводе также принимаются.
- Оценку можно записать как `30`, `30 минут`, `30м`, `1 час`, `1,5ч`, `1ч 30м`, `1:30` или `1h 30m`. Справа от заголовка показано время, оставшееся по невыполненным задачам. Диапазоны складываются по нижней и верхней границе, задачи без оценки учитываются отдельным числом. Выполненные задачи в сумму не входят. Фильтры активных и завершённых не меняют остаток дня, «На потом» считается отдельно.
- **Кнопка ссылки** открывает адрес и необязательное название. «Прикрепить» или Enter добавляет ссылку к черновику. Можно прикрепить несколько ссылок и убрать любую до создания задачи. Ссылки отображаются над названием. Если выделить всё название и вставить адрес сайта, он прикрепится ссылкой, название сохранится.
- **На потом / На сегодня** в редакторе по кнопке **⋯** меняет раздел, оставляя окно открытым. **Сохранить** применяет все правки и перенос вместе. **Отмена** или **Esc** отменяет их. Новая задача в разделе «На потом» сразу создаётся отложенной.
- **Перетаскивание** меняет порядок задач с помощью мыши.
- **×** запрашивает подтверждение удаления. Повторный клик в течение трёх секунд удаляет задачу.
- **Очистить завершённые** удаляет выполненные задачи с возможностью отмены через тост.
- **Фильтры**: Все / Активные / Завершённые / На потом.
- **Категории**: Все / Работа / Личное, независимо от фильтра списка. Каждая задача относится к работе или личному. Счётчики, остаток времени, копирование и очистка завершённых учитывают выбранную категорию. Новые задачи наследуют её, а в общем виде по умолчанию относятся к работе. Иконка категории в строке задачи открывает небольшое меню, выбор сохраняется сразу. Такая же иконка возле ввода новой задачи задаёт категорию перед добавлением. Выбор категории также остаётся в редакторе. Старые задачи без категории автоматически относятся к работе. Таймеры, привычки и заметки общие.
- Галочки в **На потом** сразу выбирают задачи для переноса, не отмечая их выполненными. Нажмите **На сегодня** в нижней строке, чтобы перенести выбранные задачи. В её меню ⋯ находятся **Выбрать все** для текущей категории и **Снять выбор**. Esc тоже снимает выбор. Перенос сохраняет категории, оценки, ссылки и взаимный порядок, его можно отменить в уведомлении.

**Cmd/Ctrl + K** фокусит поле задач. Печать вне полей и диалогов тоже переводит туда фокус. **Esc** очищает поле.

## Ежедневные привычки

Над заметками справа находится блок привычек, который всегда виден. Введите название и нажмите Enter. День привычек начинается в 09:00 по Омску (Asia/Omsk), независимо от часового пояса устройства. Ночью галочки сохраняются, а в 09:00 сбрасываются. Названия и история выполнения остаются в памяти. Счётчик привычек не влияет на прогресс задач.

Кнопка с карандашом позволяет переименовать привычку прямо в строке. Enter сохраняет название, Esc отменяет изменение. Удаление подтверждается повторным нажатием и может быть отменено в тосте. Привычки и отметки по дням сохраняются после перезагрузки.

Ручка с точками меняет порядок привычек мышью или касанием. Когда она в фокусе, стрелки вверх и вниз перемещают привычку. Порядок сохраняется после перезагрузки, отметки выполнения остаются на своих привычках. Управление общее с таймерами и заметками.

## Таймеры

По умолчанию создан Pomodoro на 52 минуты работы и 17 минут перерыва. Клик «Новый таймер» добавляет обычный таймер на 8 часов, Shift + клик добавляет Pomodoro. Таймеры независимы и ждут ручного запуска.

- **↺** сбрасывает текущую фазу на полную длительность.
- **Пауза / запуск** управляют отсчётом.
- **Ручка с точками** меняет порядок таймеров мышью или касанием. Стрелки вверх и вниз работают, когда ручка в фокусе. Порядок сохраняется после перезагрузки, отсчёт продолжается.
- **Перейти к перерыву / Вернуться к работе** переключает фазу вручную. Новая фаза ждёт запуска. При нуле таймер останавливается в состоянии `expired` и ждёт решения пользователя.
- **Клик по времени обычного таймера** меняет его полную длительность в формате `ММ:СС` или `Ч:ММ:СС`, от секунды до 24 часов. На время редактирования отсчёт ставится на паузу. Enter сохраняет новое время для запуска и сброса, Esc отменяет изменение.
- **Длительности Pomodoro** редактируются под отсчётом в минутах или формате `Ч:ММ`. Клик по времени на паузе меняет остаток текущей фазы.
- **Двойной клик** по имени переименовывает таймер. Кнопка разворачивания открывает его на весь экран.
- **×** удаляет таймер после повторного клика в течение трёх секунд.

При завершении фазы звучит сигнал, появляется браузерное уведомление и тост. Разрешение запрашивается при первом запуске таймера. Карточка и время меняют цвет, у Pomodoro тост предлагает другую фазу.

Таймеры сохраняются через временные метки. При возвращении после закрытия вкладки пропущенные фазы отмечаются завершёнными, уведомление показывается для первого такого таймера.

## Заметки

Справа показывается короткое превью каждой заметки. Клик по нему или значку раскрытия разворачивает редактор на весь экран. Текст сохраняется автоматически, закрытие редактора сразу сохраняет последние изменения. Копирование доступно в карточке и редакторе. Ссылки из текста доступны под большим редактором. Перетаскивайте заметки за ручку с точками, чтобы менять порядок, в том числе на телефоне. Если ручка в фокусе, стрелки вверх и вниз перемещают заметку. Порядок сохраняется после перезагрузки и редактирования. Удаление требует второго нажатия на ту же кнопку, её размер при подтверждении не меняется.

## Хранение

Четыре ключа в localStorage, обычный JSON:

- `todolist-minimal:v5`: задачи, категории, оценки, ссылки и раздел списка
- `todolist-minimal:timers:v3`: таймеры
- `todolist-minimal:notes:v1`: заметки
- `todolist-minimal:habits:v1`: привычки и отметки по дням, старое состояние блока сохраняется для совместимости данных

Задачи и таймеры из предыдущих версий загружаются автоматически. Идеи для дальнейших доработок записаны в [IDEAS.md](IDEAS.md).

Очистка данных сайта очищает рабочее пространство. Экспорта, резервных копий и синхронизации между устройствами пока нет.

## Установка

Проект состоит из статических файлов. Открой его через локальный HTTP-сервер. `npm ci` устанавливает инструменты проверки кода.

```bash
# Python
python3 -m http.server 8080 --directory "$HOME/code/desk"

```

## Разработка

Для проверок нужен Node.js. Сам сайт загружает `src/` напрямую через нативные ES-модули.

```bash
npm ci                # установка dev-тулов (eslint, prettier, stylelint, typescript, impeccable)
npm run format        # автоформат JS, CSS, JSON, MD
npm run lint          # ESLint на src/
npm run lint:css      # Stylelint на *.css
npm run typecheck     # tsc --noEmit по JS с JSDoc-типизацией
npm run design        # Impeccable detector на index.html и style.css (WCAG, шрифты, AI-slop)
npm run ci            # всё вышеперечисленное (это гоняет CI)
```

GitHub Actions гоняет `npm run ci` на каждом пуше в `main` и на каждом PR.

## Кастомизация

- **Длительности**: клик по цифрам обычного таймера или по «52 мин работа» и «17 мин перерыв» у Pomodoro.
- **Цвета**: CSS-переменные в начале `style.css`. `--accent` задаёт цвет работы, `--break` цвет перерыва, `--danger` цвет удаления.
- **Шрифты**: Manrope и JetBrains Mono загружаются через `<link>` в `index.html`. Удали ссылки Google Fonts, чтобы использовать локальные запасные шрифты.
- **Раскладка**: трёхколоночный грид находится в `.app`, адаптивные правила в конце `style.css`.
