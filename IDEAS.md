# Идеи для обсуждения

## После первого использования

- Посмотреть, удобна ли прокрутка списков внутри колонок. На компьютере рабочее пространство занимает один экран, привычки расположены над заметками справа. Если прокрутка задач мешает, можно попробовать сворачивать активные задачи после первых восьми.
- Сравнивать оставшуюся оценку задач с выбранным обычным таймером. Остаток по невыполненным задачам уже показан справа от заголовка. Для автоматического сравнения сначала нужно выбрать, какой таймер задаёт бюджет дня, и решить, как учитывать перерывы и задачи без оценки.
- Разделить рабочие и личные задачи внутри одного сайта. Первый вариант для обсуждения: переключатель «Все / Работа / Личное» в списке задач, независимый от «Сегодня / На потом». Каждая задача получает необязательную категорию, общий вид сохраняет весь план дня, отдельные виды показывают оценки своей категории. Новые задачи наследуют выбранную категорию. Таймеры, заметки и привычки остаются общими. Пока не реализовывать. Сначала обсудить, нужен ли отдельный рабочий бюджет времени и как показывать принадлежность задачи без лишних цветных плашек.
- Добавить дату к отложенным задачам. Пока «На потом» служит общей полкой, а перенос на сегодня выполняется вручную.
- Сделать экспорт и импорт задач, таймеров и заметок в JSON. Это даст локальную резервную копию без аккаунтов и сетевых сервисов.
- Обсудить, нужен ли режим чтения заметки с оформлением Markdown. Сейчас заметка открывается в большом текстовом редакторе, ссылки доступны отдельно.
- Если задач станет много, добавить поиск по названию и прикреплённым ссылкам.
- Для привычек обсудить выбор дней недели и просмотр отметок за неделю. Пока каждая привычка повторяется ежедневно, история дат сохраняется без отдельного календаря.

## Что проверено в этом проходе

По рекомендациям [Impeccable](https://impeccable.style/) проверены доступность управления, читаемость, поведение длинного содержимого, адаптивность и согласованность оформления. Тёмная тема, Manrope, JetBrains Mono и цветовые акценты сохранены по пожеланиям пользователя.

- Уменьшены заголовок и верхние отступы. Длинный список задач прокручивается внутри центральной колонки.
- Сочетания клавиш работают без отдельных подсказок в интерфейсе. Перенос задач находится в редакторе по кнопке ⋯.
- Длинные таймеры показывают цельный отсчёт `ЧЧ:ММ:СС` по ширине карточки и полоску оставшегося времени. Короткие используют `ММ:СС` внутри круга. Новые таймеры ждут ручного запуска.
- Убраны декоративные свечения таймеров. Состояние завершения остаётся заметным по цвету карточки и времени.
- У заметок справа нет редактора с внутренним скроллом. Превью открывает полноэкранный редактор, копирование доступно в обоих местах.
- Формы получили подписи, действия с иконками получили доступные названия. Диалоги удерживают клавиатурный фокус и закрываются по Esc.
- Добавлены раскладки для планшета и телефона. Проверены снимки Chromium при ширине 1440 и 390 пикселей.
- Цвета вынесены в CSS-переменные. Детектор `npm run design` завершился без замечаний.

Для отдельного обсуждения остаётся изменение порядка задач с клавиатуры и на сенсорном экране. Сейчас перетаскивание рассчитано на мышь. Проверка на физическом телефоне в этом проходе не проводилась.
