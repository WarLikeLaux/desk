# desk

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

[English](README.md) | Русский

desk — личное рабочее пространство на десктопе: тудулист и набор помидор-таймеров на одной тёмной странице. Задачи и таймеры сохраняются в localStorage. Никаких сборок, никакой телеметрии, никаких сетевых вызовов. Открыл страницу, напечатал, работаешь.

Раскладка — три колонки: слева таймеры, в центре задачи, справа пустой слот под будущее.

## Задачи

Минимальный список с тем, что нужно, и без остального.

- **Enter** добавляет задачу в конец активной секции. Печать где угодно на странице фокусит инпут — кликать не надо.
- **Клик** по чекбоксу — выполнено. Выполненные задачи уезжают вниз и зачёркиваются.
- **Двойной клик** по задаче — переименовать. Enter сохраняет, Esc отменяет.
- **Перетащи** за ручку (видна по hover), чтобы изменить порядок.
- **Hover** показывает номер позиции и × удаления. Клик × один раз — «Удалить?», дважды за три секунды — подтверждение.
- **«Очистить завершённые»** в футере удаляет все выполненные задачи с тостом-отменой.
- **Фильтры**: Все / Активные / Завершённые — клик по вкладке переключает, счётчики обновляются.

**Cmd/Ctrl + K** фокусит инпут задач откуда угодно. **Esc** очищает инпт.

## Таймеры

Помидор — фаза работы, потом фаза перерыва. desk стартует с одним таймером (52 мин / 17 мин) и позволяет добавлять ещё сколько нужно. Каждый таймер независимый.

- **↺** сбрасывает текущую фазу на полную длительность.
- **⏸** пауза; **▶** продолжить.
- **«→ перерыв» / «→ работа»** переключает фазу вручную. Таймер **не** переключается сам — когда отсчёт доходит до нуля, он останавливается в состоянии `expired` и ждёт твоего решения.
- **Клик «52 мин работа» / «17 мин перерыв»** меняет любую длительность (1–240 минут).
- **Двойной клик** по имени таймера — переименовать.
- **Клик ×** один раз — «удалить?», дважды за три секунды — подтверждение.

Когда фаза заканчивается, срабатывают три уведомления, чтобы пропустить было сложно: бип (Web Audio, восходящий тон для конца работы, нисходящий для конца перерыва), нативная браузерная нотификация (разрешение запрашивается при первом использовании) и тост внутри приложения с прицепленной кнопкой переключения фазы. Бордер карточки становится accent-цветом, цифры времени — accent, лейбл фазы пульсирует, кнопка «→ перерыв» / «→ работа» становится самым очевидным следующим кликом.

Таймеры сохраняются через timestamp. Закрыл вкладку, вернулся через час — пропущенная фаза отлавливается и уведомление срабатывает один раз для самого важного таймера.

## Хранение

Два ключа в localStorage, обычный JSON:

- `todolist-minimal:v2` — задачи
- `todolist-minimal:timers:v2` — таймеры

Очистка данных сайта очищает рабочее пространство. Никакого экспорта, бэкапа, синхронизации.

## Установка

Проект — набор статических файлов плюс Node-тулчейн для линтинга и проверки типов. Открыть локально можно любым статическим HTTP-сервером; `npm ci` нужен только если хочешь запускать проверки.

```bash
# Python
python3 -m http.server 8080 --directory "$HOME/code/desk"

# Или просто открой файл
xdg-open "$HOME/code/desk/index.html"
```

## Разработка

Требует Node.js ≥ 20 для тулов. Сам сайт не требует сборки и не имеет рантайм-зависимостей — `src/` грузится браузером напрямую через нативные ES-модули.

```bash
npm ci                # установка dev-тулов (eslint, prettier, stylelint, typescript)
npm run format        # автоформат JS, CSS, JSON, MD
npm run lint          # ESLint на src/
npm run lint:css      # Stylelint на *.css
npm run typecheck     # tsc --noEmit по JS с JSDoc-типизацией
npm run ci            # всё вышеперечисленное (это гоняет CI)
```

GitHub Actions гоняет `npm run ci` на каждом пуше в `main` и на каждом PR.

## Кастомизация

- **Длительности**: клик «52 мин работа» или «17 мин перерыв» на любой карточке таймера.
- **Цвета**: каждый цвет — CSS-переменная в начале `style.css` (`:root { ... }`). `--accent` — цвет работы, `--break` — цвет перерыва, `--danger` — удаление.
- **Шрифты**: `style.css` грузит Inter и JetBrains Mono с Google Fonts. Удали `<link>` в `index.html`, чтобы убрать сетевой вызов совсем.
- **Раскладка**: трёхколоночный грид живёт в `.app` в `style.css`. Меняй `grid-template-columns`, чтобы расширить колонку или скрыть одну.
